# Spotify Record Collection

This project is a React app built with Vite and uses npm as its package manager.

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run start
```

The app will be available at http://localhost:5173 by default.

## Available Scripts

```bash
npm run start
```

Runs the Vite dev server.

```bash
npm run build
```

Builds the app for production.

```bash
npm run preview
```

Serves the production build locally for previewing.

## Notes

- This project includes a `package-lock.json`, which indicates npm is the active package manager.
- The app is configured for Vite rather than the older Create React App defaults.
